# Security

Please don't report security problems in public issues or discussions.

Report them privately instead: go to the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainer sees the report.

It helps to include:

- what you found, and where (the page, the feature, or the API path);
- how to reproduce it;
- what someone could do with it.

You'll get a reply within a few days. Please give us time to fix the problem before telling anyone else about it.
